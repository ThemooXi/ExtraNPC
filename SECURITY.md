# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Contact the author privately:

- Discord: **@m_1z.4**
- Support server: [https://discord.com/invite/fJTSA6vnVQ](https://discord.com/invite/fJTSA6vnVQ)

Include:

1. Affected version
2. Steps to reproduce
3. Impact (e.g. console command injection, permission bypass)

We will acknowledge reports as soon as possible and coordinate a fix / disclosure timeline.
