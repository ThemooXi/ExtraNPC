[CENTER][S]                                                            [/S][/CENTER]
[B][SIZE=5]About[/SIZE][/B]
ExtraNPC is a standalone Paper plugin for creating and managing NPCs.
Build player-model NPCs, animals, and mobs with a full in-game GUI — skins, click commands, holograms, particles, and a built-in trade shop.

[CENTER][S]                                                            [/S][/CENTER]
[B][SIZE=5]Features[/SIZE][/B]
[LIST]
[*][B]Player NPCs[/B] — native Paper Mannequin where available, compatible skinned fallback on older versions
[*][B]Mob NPCs[/B] — animals and mobs as frozen NPCs
[*][B]Skins[/B] — Mojang player name or texture URL
[*][B]Click actions[/B] — player: · console: · message:
[*][B]Shop system[/B] — trade editor + villager merchant UI
[*][B]Extras[/B] — holograms, particles, look-at-player, glow, cooldown, permissions
[*][B]PlaceholderAPI[/B] — optional (works without it)
[*][B]Admin tools[/B] — sneak-click edit · clickable help in chat
[/LIST]

[CENTER][S]                                                            [/S][/CENTER]
[B][SIZE=5]Requirements[/SIZE][/B]
[LIST]
[*]Server: Paper (or compatible fork) 1.19.4 through 26.2
[*]Java: 17+ bytecode; use the Java version required by your server
[*]Dependencies: None required
[/LIST]

[CENTER][S]                                                            [/S][/CENTER]
[B][SIZE=5]Installation[/SIZE][/B]
[LIST=1]
[*]Download ExtraNPC-1.0.0.jar
[*]Put the jar in your plugins folder
[*]Restart the server
[*]Run /extranpc gui
[/LIST]

[CENTER][S]                                                            [/S][/CENTER]
[B][SIZE=5]Quick start[/SIZE][/B]
[CODE]
1. /extranpc gui           → create an NPC
2. Set name / skin / cmds  → configure it
3. Open Shop               → add trades
4. Right-click the NPC     → use it in-world
[/CODE]
