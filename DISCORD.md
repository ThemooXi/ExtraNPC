# 🧍 ExtraNPC
### Standalone Advanced NPC Framework for Paper

✨ Create beautiful NPCs in seconds — player models, mobs, shops, and a full GUI.

---

## ✨ Features

**🧍 Player NPCs**
- Real player model (Paper Mannequin)
- Skins by name or texture URL
- Look-at-player · glow · holograms

**🐾 Mob NPCs**
- Animals & mobs as frozen NPCs
- Quick type select from GUI

**🖱️ Click Actions**
- `player:` · `console:` · `message:`
- Optional PlaceholderAPI

**🛒 Shop System**
- Built-in trade editor
- Villager merchant UI

**🛠️ Admin Tools**
- Full in-game GUI
- Sneak-click to edit
- Clickable help & about

---

## 📜 Commands

> `/extranpc` · `/enpc` · `/npc`

`/extranpc gui`
`/extranpc create <id> [type]`
`/extranpc edit <id>`
`/extranpc delete <id>`
`/extranpc list`
`/extranpc move <id>`
`/extranpc tp <id>`
`/extranpc reload`
`/extranpc help`
`/extranpc about`
